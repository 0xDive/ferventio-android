# Security

## Supported versions

Only the latest public beta receives security fixes. Modified or unofficial builds are not supported.

## Reporting a vulnerability

Do not open a public issue. Use a [private GitHub security advisory](https://github.com/0xDive/ferventio-android/security/advisories/new).

Include the affected version and flavor, impact, reproduction steps and a minimal proof of concept. Do not include real tokens, private chat content or data belonging to other users.

If a secret may have been exposed, revoke or rotate it before removing it from Git history or issue content.
