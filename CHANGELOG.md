# Changelog

Notable user-facing changes are recorded here. Ferventio follows semantic versioning for public releases; Android `versionCode` remains a separate monotonically increasing distribution counter.

## [Unreleased]

## [0.0.2] - 2026-08-04

Certificate pinning hotfix.

- Fixed release certificate pin configuration that prevented Ferventio web authentication.


## [0.0.1] - 2026-08-03

Initial public beta.

- Twitch chat, replies, moderation events and user cards
- Multi-channel workspaces and notification rules
- Twitch, BetterTTV, FrankerFaceZ and 7TV emotes
- Local Room history, settings backup and restore
- FOSS WebSocket and Play/FCM distributions
- Light, dark and AMOLED themes
